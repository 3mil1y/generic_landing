# Landing Page Genérica

Uma landing page moderna e responsiva, desenvolvida com HTML5, CSS3 e JavaScript puro, sem a necessidade de frameworks ou bibliotecas adicionais.

## 🚀 Recursos

- Design totalmente responsivo
- Navegação suave
- Animações e efeitos visuais
- Formulário de contato funcional
- Otimizado para SEO
- Código limpo e bem organizado
- Fácil personalização

## 🛠️ Estrutura do Projeto

```
project/
├── src/
│   ├── assets/
│   │   ├── images/      # Imagens e fotos
│   │   └── icons/       # Ícones e SVGs
│   ├── scripts/         # Arquivos JavaScript
│   └── styles/          # Estilos CSS
├── data/               # Dados dinâmicos (JSON)
├── index.html          # Página principal
├── favicon.ico         # Ícone do site
└── README.md
```

## 🎨 Personalização

### Cores
As cores principais podem ser alteradas no arquivo `src/styles/main.css` através das variáveis CSS na raiz do documento:

```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #1e40af;
    --accent-color: #3b82f6;
    --text-color: #1f2937;
    --text-light: #6b7280;
    --light-bg: #f3f4f6;
    --white: #ffffff;
    --dark: #111827;
}
```

### Imagens
Substitua as imagens de exemplo na pasta `src/assets/images/` pelas suas próprias imagens. As imagens principais são:
- `hero-image.jpg` - Imagem principal da seção hero
- `about.jpg` - Imagem da seção "Sobre Nós"
- `portfolio1.jpg`, `portfolio2.jpg`, `portfolio3.jpg` - Imens de portfólio

### Conteúdo
Edite o arquivo `index.html` para personalizar o conteúdo do site, como textos, links e informações de contato.

## 🚀 Como usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/landing-page-generica.git
   ```

2. Navegue até a pasta do projeto:
   ```bash
   cd landing-page-generica
   ```

3. Abra o arquivo `index.html` em seu navegador ou inicie um servidor local.
